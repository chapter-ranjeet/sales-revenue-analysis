# Sales & Revenue Analysis Dashboard

An interactive sales analytics dashboard built with Streamlit, Pandas, NumPy, and Plotly. It includes a polished light interface, dynamic filters, KPI cards, interactive charts, automated business insights, CSV/XLSX upload support, and filtered data export.

## Features

- White dashboard interface with bold black headings and responsive layout.
- Synthetic demo data generated automatically when no file is uploaded.
- Upload support for CSV and XLSX files.
- Required-column validation for uploaded files.
- Date-range filtering.
- Region filtering.
- Category filtering.
- Executive KPIs:
  - Total revenue
  - Net profit
  - Profit margin
  - Units sold
  - Average order value
- Interactive Plotly visualizations:
  - Monthly revenue trend
  - Revenue share by region
  - Revenue versus profit by category
  - Top five products by revenue
- Automated insights for the top category, top region, best-selling product, and margin health.
- Filtered data explorer with CSV download.
- Cached data loading for faster Streamlit reruns.

## Requirements

- Python 3.10 or newer recommended
- Pip
- A modern web browser

## Installation

Clone the repository and enter the project directory:

```bash
git clone https://github.com/chapter-ranjeet/sales-revenue-analysis.git
cd sales-revenue-analysis
```

Create and activate a virtual environment:

### Windows PowerShell

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

### macOS or Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install dependencies:

```bash
python -m pip install -r requirements.txt
```

## Run the Dashboard

Start Streamlit with:

```bash
python -m streamlit run app.py
```

Then open the local URL shown in the terminal, normally:

```text
http://localhost:8501
```

To use another port:

```bash
python -m streamlit run app.py --server.port 8503
```

## Using the Dashboard

1. Open the dashboard in a browser.
2. Use the sidebar to upload a CSV or XLSX file, or continue with the generated demo data.
3. Select a date range.
4. Select all regions and categories, or turn off the select-all controls and choose specific values.
5. Review the KPI cards and interactive charts.
6. Read the automated insights below the charts.
7. Expand the data explorer to inspect filtered rows.
8. Download the filtered data as a CSV file when needed.

If no rows match the selected filters, the dashboard displays an empty-state message instead of rendering invalid charts.

## Upload Data Format

Uploaded files must contain these columns:

| Column | Description | Expected type |
| --- | --- | --- |
| `Order_Date` | Date of the order | Date or date-like text |
| `Category` | Product category | Text |
| `Product` | Product name | Text |
| `Region` | Sales region | Text |
| `Units_Sold` | Number of units sold | Numeric |
| `Revenue` | Revenue generated by the order | Numeric |
| `Profit` | Profit generated by the order | Numeric |

CSV files should be UTF-8 encoded when possible. Excel files must be `.xlsx` files.

Invalid dates are removed. Invalid numeric values are converted to zero. Files missing required columns are rejected with a validation message.

## Synthetic Data

When no upload is selected, `data_generator.py` creates a reproducible demo dataset covering January 2025 through December 2026. The generator includes:

- Five regions
- Five product categories
- Multiple products per category
- Seasonal demand patterns
- Weekday and weekend order differences
- Year-over-year growth for 2026
- Regional market-share weighting
- Variable prices, units, and profit margins

The default random seed is `42`, so the generated demo data is stable between runs.
